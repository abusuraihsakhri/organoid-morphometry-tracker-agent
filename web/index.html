Organoid Metric Screening

Local, browser-based evaluation of this repository's deterministic threshold rules.

Research demonstration, not a validated morphometry assay. This tool evaluates numeric values and flags; it does not segment microscopy images, measure volume, calculate lumen-to-wall ratios, estimate IC50, or provide clinical decision support. The thresholds are project defaults, not established biological reference intervals.
